Write to Build Understanding Pilot Support

Welcome to MAXLiteracy®!
We’re so excited to share this program with you and your students!

The Write to Build Understanding lessons in this program have been designed with a yearlong gradual release of responsibility from teacher to student. Because you are beginning implementation mid-year, we have provided a set of targeted materials to support successful implementation.

These materials are intended to help supplement some of the bedrock instruction that students would have experienced in the first few units of the program. They are not intended to replicate or reteach every lesson from the earlier units. Instead, they highlight the experiences that are most important for supporting a smooth transition into the program.
